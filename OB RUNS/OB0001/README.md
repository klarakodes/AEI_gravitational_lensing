## Runs used:
The following runs were used in our reductions (see the .html or .txt observing logs for all info for the observing night):
- **run0001** = 1x1 bias frame
- **run0004** = 4x4 bias frame
- **run0005** = 1x1 flat field frame
- **run0007** = science frames 
- **hipercam_fmap.hcm** = 1x1fpair.hcm (to make fringe map for z-band)

## HCAM reduction pipeline files:
Files generated by the reduction pipeline:
- makebias -> 1x1bias.hcm
- makebias -> 4x4bias.hcm
- makeflat -> 1x1flat.hcm
- averun -> averun0007.hcm
- setaper -> masterapertures.ape
- genred -> red0007.red
- reduce -> log0007.log
- config file -> masterconfig.txt 
    - contains colour transformed magnitudes from Panstars to superSDSS 
    - use log2lc.py to convert the instrumental magnitudes
- log2lc.py -> FINALrun0007_g.dat, FINALrun0007_r.dat, FINALrun0007_i.dat, FINALrun0007_z.dat, FINALrun0007_u.dat
